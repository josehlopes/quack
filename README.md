## O que é o Quack?

O Quack é uma plataforma educativa para programadores que busca reduzir a barreira de entrada na área de TI e combater a evasão nos cursos. 

O problema que buscamos resolver envolve dados reais:
- A Brasscom estima uma demanda de 797 mil talentos em tecnologia de 2021 a 2025.
- O Mapa do Ensino Superior no Brasil 2023 aponta que a evasão em cursos de TI supera a média geral.

O Quack ajuda os estudantes através de guias de estudo (roadmaps) e conteúdo prático em português, além de um sistema gamificado com emblemas para manter o engajamento e a motivação.

## Tecnologias do Backend

Para a construção da API, utilizamos:
- Java
- Spring Boot
- PostgreSQL (Banco de dados)

A arquitetura foi pensada para ser organizada e facilitar a manutenção, seguindo princípios de divisão de responsabilidades.

## Como rodar a API

1. Clone o repositório.
2. Certifique-se de ter o Java 21 e o Maven instalados.
3. Configure a conexão com o banco de dados PostgreSQL no arquivo de propriedades.
4. Execute o projeto com o comando `mvn spring-boot:run`.

A documentação da API pode ser acessada via Swagger após iniciar o projeto localmente.
